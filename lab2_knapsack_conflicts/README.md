## Постановка

Задача 0/1 рюкзака с дополнительными ограничениями-конфликтами:

- Каждый предмет имеет вес `w_i` и ценность `v_i`.
- Есть ёмкость рюкзака `W`.
- Есть набор пар предметов, которые **нельзя** брать одновременно.

**Цель:** максимизировать суммарную ценность при соблюдении обоих типов ограничений.

**Представление особи:** бинарная строка длины `n` (1 — предмет взят, 0 — нет).

| Элитизм               | 2 особи           |

**Операторы:**
- Селекция: турнирная
- Кроссовер: одноточечный / равномерный
- Мутация: битовая
- Обработка ограничений: **ремонт** (основной) и **штрафы**

---

## Ремонт (repair)

1. Для каждой конфликтующей пары оставляем предмет с большим отношением `value/weight`.
2. Если вес превышает ёмкость — последовательно удаляем предметы с наименьшим `value/weight`, пока решение не станет допустимым.

После ремонта все особи популяции всегда допустимы → фитнес = ценность.

---

## Сравнение подходов

В экспериментах сравниваются:

1. `repair` + one-point crossover  
2. `repair` + uniform crossover  
3. `penalty` (коэффициент 40) + one-point  
4. `penalty` (коэффициент 120) + one-point  

Также сравнивается с:
- жадной эвристикой (по value/weight с учётом конфликтов);
- случайным допустимым поиском (5000 попыток с ремонтом).
