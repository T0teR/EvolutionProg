# Лабораторная работа № 1  
## Многомерная оптимизация сложной функции генетическим алгоритмом

**Вариант:** 2 (функция Розенброка, размерность \(d = 7\))  
**Область поиска:** \([-5, 10]\)  
**Язык:** Python 3

---

## Описание

Реализован базовый генетический алгоритм для непрерывной оптимизации функции Розенброка:

$$
f(\mathbf{x}) = \sum_{i=1}^{d-1}\Bigl[100(x_{i+1}-x_i^2)^2 + (1-x_i)^2\Bigr], \quad d=7
$$

**Глобальный минимум:** $\mathbf{x}^* = (1,1,\ldots,1)$, $f(\mathbf{x}^*) = 0$.

### Операторы алгоритма

| Оператор              | Реализация                          |
|-----------------------|-------------------------------------|
| Представление         | Вещественный вектор                 |
| Инициализация         | Равномерная в \([-5, 10]\)          |
| Селекция              | Турнирная (размер = 3)              |
| Кроссовер             | Арифметический (\(p_c = 0.8\))      |
| Мутация               | Гауссовская (\(p_m = 0.1\), \(\sigma = 0.5\)) |
| Обработка границ      | Clipping                            |
| Элитизм               | 1 особь                             |
| Критерий остановки    | 10 000 вычислений целевой функции   |

## Запуск

Из корневой папки проекта выполните:

```bash
python main.py
```

Программа автоматически:

1. Запускает **20** независимых прогонов генетического алгоритма с популяцией **50**
2. Запускает **20** независимых прогонов генетического алгоритма с популяцией **100**
3. Запускает **20** независимых прогонов случайного поиска
4. Сохраняет результаты в `results/*.csv`
5. Строит и сохраняет графики в `plots/`

### Воспроизводимость

Все запуски используют фиксированный базовый seed:

```
BASE_SEED = 42
```

Для \(k\)-го запуска (\(k = 1\ldots20\)) используется `seed = 42 + (k - 1)`.
